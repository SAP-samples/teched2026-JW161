# JW161 - SAP's Compositional Design System: Author and Render Your Own UIs

## Description

This repository contains the hands-on material for the session **JW161 – SAP's
Compositional Design System: Author and Render Your Own UIs**. During the
session, you explore the **CompUI Tooling (Tech Preview)**: inspect the
primitives and composites in the catalogue, generate finished data-bound views from
plain-language prompts, author a brand-new composite from a description, and
watch the system's reasoning as it chooses *how* to render *what* you asked for.

## Overview

The Compositional Design System separates **what** you want to see from **how**
it is shown. You describe intent; the system selects a pre-approved building
block (a **composite**), binds it to data, and renders it — governed throughout
by the **design knowledge (rules)** that ships with every component, and
explained by a visible **Reasoning flow**.

The session runs against the standard SAP **SFlight** travel scenario (travels,
bookings, agencies, prices, status), so every preview and generated view is
bound to real data.
